# StockFlow

StockFlow is a web-based Inventory and Order Management System
designed to help businesses manage products, stock movements,
customers, and orders.

## Project Status

Currently in the project initiation and planning phase.

## Objectives

- Manage product information.
- Monitor inventory and stock movements.
- Manage customer information.
- Record and manage orders.
- Provide inventory and business reports.

## Technology Stack
